## Overview
Data and code to (partially) replicate the results from [Nogueira (2025)](https://drive.google.com/file/d/1yh72-KW88E-0PPM7krZzIIIHKNZm99OC/view?usp=sharing)

There are 3 files in this replication package. One .rds file, which contains the data used in the paper, and two .R files, which construct the analysis in the paper using R - one file runs the main analysis and the other contains helper functions.

## Instructions to Replicators

1. Save the data file in the same repository as the .R files.
2. Run cb_comms_analysis.R. It will automatically import the functions from cb_comms_functions.R, generate the .tex tables, and save the figures to the figures folder.
